# Nunito

Unmodified Nunito v32 variable WOFF2 fonts (normal, weights 300–800), served
locally so booklet pagination and PDF exports use the intended face offline.
The five Unicode subsets and their CSS ranges come from
https://fonts.googleapis.com/css2?family=Nunito:wght@300..800&display=swap
(retrieved 28 September 2026). Original binaries:
https://fonts.gstatic.com/s/nunito/v32/ followed by each WOFF2 filename here.
