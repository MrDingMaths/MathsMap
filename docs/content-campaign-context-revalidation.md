# Scoped prerequisite revalidation

Use the ordinary reconciliation, author preparation/staging and independent review path. A prerequisite-only drift preserves an immutable `context-prior-review-*.json` reference; it does not preserve current acceptance. Source or live-pair drift continues through full review. New stages retain an immutable dependency reference; legacy full inline contexts are recovered only when they reconstruct the exact historical dependency hash.

An unchanged candidate can submit `contextRevalidation` to the existing `record-review` input after the different native reviewer has actually read and acknowledged the complete current prerequisite packs. The confirmation uses profile `prerequisite-context-revalidation-v1` and binds `actorId`, `priorReferenceHash`, `oldStageHash`, `currentStageHash`, `candidateHash`, `oldDependencyHash` and `currentDependencyHash`.

Its `parents` contain exactly every changed parent: `id`, `oldTheoryHash`, `currentTheoryHash`, `scopeStillValid: true` and a substantive observation of the full taught context. Its `methods` contain every current coverage method: `id`, the exact method `hash`, a substantive source/method/scope observation and `requiresFreshDerivation`. Mark this true wherever the changed teaching affects the assessed method; supply fresh whole-item outcomes (including all MCQ options) for those mappings. Any changed prerequisite step sequence conservatively requires fresh derivations for all methods, regardless of the confirmation.

Only accepted original outcomes with exact unchanged candidate, source selection, scope, coverage and item hashes can be retained. The current reviewer must differ from both current and historical authors. The normal review still requires current Theory/source observations, source-gap decisions, removal dispositions, step-repair checks and applicable visual evidence. Omission of this explicit confirmation leaves the original full-review path unchanged. Old arithmetic evidence and old dependency hashes remain distinct in the new review; historical receipts are never edited.
