# Teaching module bank

Reusable teaching modules are stored here as `mathsmap-teaching-module-v1` JSON through explicit Studio bank saves. Questions are saved first; module references include their pinned revisions and snapshots. `status: approved` is a compatibility marker for a bank save, not a separate review gate.

The Linear Relationships modules come from the user's revised booklet. Source identities and dependent groups are recorded in `docs/linear-relationships-bank-index.json`. Bank and booklet edits do not automatically synchronise.
