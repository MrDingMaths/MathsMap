# Teaching revision — 16 September 2026

Authority: the user's approved “Data Visualisation: clearer examples and vertical teaching pairs” implementation plan. This is an authored replacement of teaching content in **Data Visualisation 1 v1**, not a claim that the original source contains the revised datasets. Original PDF/DOCX, inventory descriptions, earlier corrections and revision 4 remain evidence.

All 13 original worked-example groups and their 13 guided-practice groups were reviewed. Separating numerical-frequency interpretation and the two stem-and-leaf miniatures produces 15 matched model/practice pairs. The nine former side-by-side links are removed. The 102 independent questions, their answers, classifications, order and exercise pagination settings are preserved.

| Topic | Mathematical focus and matched practice |
| --- | --- |
| Frequency tables | Retain the 12-car colour construction. Ten household observations reduce counting. A separate four-row numerical model distinguishes six observations, seven cars, mode one and maximum observed two. Guided interpretation uses the preceding household table, including zero frequency for four cars. |
| Pictograms | Three categories in each task. Explicit division by the key connects frequencies to whole and half symbols; guided counts use the same operation with a different key. |
| Column graphs | Retain both datasets. A vertical Name/Height table accompanies the model. Explain scale, column height, equal width and equal spacing, with the longer explanation below the table/graph row. |
| Line graphs | Retain five readings in each task. Vertical tables reduce horizontal scanning. Time order and interpolation precede midpoint arithmetic, which is a check on the graphical estimate. |
| Dot plots | Twelve observations per task retain frequency stacks and concentration. The model's isolated 19 contrasts with guided data having no clear outlier. Features are explained from positions and gaps, without a second counting exercise. |
| Stem-and-leaf plots | Ten unsorted observations per task retain repeats, zero leaves and an empty stem. Show splitting, ordering and a key. Each back-to-back/negative miniature now immediately precedes its own guided check. |
| Sector/divided-bar graphs | Reverse a general percentage before finding another category: 40% and $240 give $600; 30% is $180. Guided 30% and $90 give $300; 40% is $120. Retain half/quarter recognition in theory. Construction explicitly models Bus angle 108° and length 3 cm, retaining the physically calibrated 10 cm bars. |
| Histograms/polygons | One small model dataset serves the explanation and construction. Both model and guided data include an empty class. Distinguish half-integer boundaries, top centres and the two zero endpoints. |
| Cumulative frequency/ogives | Retain the five-row cumulative tables. Compare strict, inclusive, exact and total counts at the same threshold. Reuse completed totals for ogives so upper-boundary placement is the new demand. |
| Graph choice | Retain all three comparison graphs and the four-week dataset. Responses select and justify representations; percentage arithmetic has been removed from selection questions. |

Native arrangements place data/instructions on the left and graphs on the right, usually 40:60 with a 4 mm gutter. The three-column cumulative table uses equal-width halves for a readable heading. Meaningful sector/bar pairs remain together. Worked Example is above Guided Practice; handwriting space and readable labels take precedence over squeezing theory onto the same page.

The numerical model deliberately uses easy arithmetic while retaining general cases. Repetition is retained when it expresses frequency. Unchanged independent practice continues to supply larger datasets and broader application.
